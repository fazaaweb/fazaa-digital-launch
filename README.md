# فزعة ويب 

أنت مصمم UI/UX احترافي ومطور Frontend Senior ومتخصص في بناء مواقع الشركات الحديثة عالية الجودة.

مهمتك:

تنفيذ المرحلة الأولى من الموقع الرسمي لشركة «فزعة ويب | Fazaa Web» بناءً على الهوية والخطة المعتمدة، وتشمل هذه المرحلة:

1. الهوية البصرية الأساسية.

2. Navbar.

3. Hero Section.

4. جميع الحركات والتفاعلات المرتبطة بهذه الأجزاء.

ثامنًا: الفيديو

━━━━━━━━━━━━━━━━━━━━

الفيديو هو عنصر أساسي في Creative Direction.

المشهد يحتوي على:

- بيئة تقنية داكنة.

- إضاءة زرقاء.

- كرة/جسم كروي مضيء في المنتصف.

- عنصر هندسي مضيء.

- عناصر تقنية وأيدٍ حول المشهد.

مهم جدًا:

لا تضع النص فوق أهم منطقة مضيئة في الفيديو بطريقة تحجبها.

يجب أن يظهر العنصر المركزي بوضوح.

Desktop:

اضبط Position/Crop بحيث يبقى المشهد الرئيسي واضحًا.

Mobile:

لا تستخدم نفس Crop الخاص بالDesktop بشكل أعمى.

أعد ضبط:

background-position / object-position

حسب حجم الشاشة حتى يبقى العنصر الرئيسي ظاهرًا قدر الإمكان.
